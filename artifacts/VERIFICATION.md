## 0.2.0 大麦自动视觉学习试用

- 新安装包 `TiaoTiao-0.2.0-debug.apk`，versionCode 8；已覆盖安装到小米 14 Pro / Android 16，保留网关凭据、普通规则与应用选择。手机安装 APK 与交付 APK 的 SHA-256 完全一致，见 `SHA256SUMS`。
- 大麦原先仅提供 7 个无障碍节点，跳过进度控件无文字；普通节点路径因此不发起 Jev 请求。新增系统截图、随包 ML Kit 中文 OCR、节点/画面信号融合及 Vercel 视觉学习。当前默认视觉模型为 `google/gemini-2.5-flash-lite`，普通 Jev 配置独立保留；没有接入 PaddleOCR 或 RapidOCR。
- 学习最多采集两份错开的遮挡图片，离开广告后继续分析，结果晚到只缓存。真实识别请求观察到约 4–7 秒，不适合要求首次开屏等待云端响应。无数字倒计时的大麦广告先自动观察一次自然结束，记录本机显示时长基线。
- 候选使用当前应用、版本、完整界面指纹、广告信号和目标局部特征复核；优先关联当前小型可点击控件，找不到才使用受限手势。每个会话最多一次点击，没有人工确认浮层。不同会话须同时通过提前结束的时序证据与视觉 AI 对首页/广告消失/非详情页/非系统提示的复核，累计至少两次才 ACTIVE。模型自报置信度仅为筛选条件，不作为准确率或单独成功证明。
- 真机自动产生两次独立、时序有效的成功证据并进入 ACTIVE；随后继续复用。最终一次冷启动记录：收到事件 → 本地关联目标并点击 → 两帧页面变化与已验证首页局部特征匹配 → “智能规则本地复用及结果检查通过，未请求云端模型”。该轮没有学习/结果复核请求记录，也没有人工操作确认；这是程序观察证据，不等同人工逐帧验收，也不是网络抓包统计。
- 结果观察使用窗口元数据与截图，避免等待完整首页节点树造成数秒延迟；首页局部模板只从 AI 接受且时序有效的稳定两帧生成，要求与广告明显不同，平坦、变化或不匹配的模板不用于通过本地复核。导入清除模板及外部证据，需本机 AI 重新识别，不能直接信任共享 ACTIVE 标记。
- 真实复测仍有小按钮 OCR 漏检、首轮未执行点击的情况，不能宣称大麦所有广告均可跳过。当前自动试用限定大麦；其他应用继续旧流程。首页特征变化时可能回退云端复核；不承诺全部已知场景均零请求。对识别未通过的方案只允许有限次重新学习；用户明确停用始终保留。
- 核心 JVM 36 项、Android JVM 8 项测试通过；APK/测试 APK 构建与 Lint 通过（Error/Fatal 0）。独立 API 36 模拟器显式指定 serial 运行两项端到端测试，`OK (2 tests)`：普通人工确认/离线复用与画布广告 OCR/自动尝试/跨会话启用/关闭后不操作。最新模拟器测试用时 19.080 秒，未请求云端模型。测试 APK 未安装到真实手机。
- 图像遮挡不是完整个人信息识别；只有 OCR 发现的非必要文字被遮挡，图像中仍可能保留人物、物品和未识别文字。原图仅内存处理，缓存与发送的是遮挡 JPEG，最多 8 份；成功后删除，未确认目标样本在应用运行清理时按 24 小时过期。没有把真实密钥、样本或屏幕内容提交到仓库。
- 开源库候选与比较计划见 `docs/RECOGNITION_OPTIONS.md`。智能规则独立 JSON 导入/导出已实现；普通 WebDAV 同步暂不包含智能规则。其他品牌、Android 11–15、更多真实广告变体以及智能规则跨设备效果尚未实测。
