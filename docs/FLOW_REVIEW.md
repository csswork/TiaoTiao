# 通用检测流程修订

日期：2026-11-03，时区 Asia/Shanghai。版本 0.3.7–0.3.9。未 commit 或 push。

## 修复的流程缺口

| 问题 | 当前处理 |
| --- | --- |
| 自动负判暂停后，同目标重新识别无法覆盖，却仍显示已缓存 | 自动暂停退避 15 秒、60 秒、之后 5 分钟；到时新 AI 识别或严格的跨帧明确控件证据可恢复候选，清除旧证明并保留失败计数；保存结果区分成功、已有和等待 |
| 相同负结果去重 10 分钟，立即重开仍无法重学 | 负结果去重缩至 15 秒；失败记录、模型配置及手动重学修订加入样本标识 |
| 界面首次出现控件就点击，手势完成被当作应用已接收 | 图像目标先跨帧确认稳定，使用 80 ms 短点；明确区分系统手势完成和真实广告退出 |
| 缓存点击无效后无后续动作 | 只有新截图确认同应用、版本、窗口、尺寸、广告与原关闭目标未变时，最多重新校准补点一次；不对变化画面、首页或节点动作盲目追加触控 |
| 结果截图过早、原广告仍在就结束观察 | 有界观察最多约 3.5 秒，保留最后两帧；原目标仍在或画面未变不能被 AI 正判覆盖 |
| 已退出的广告窗口拖延点击结果截图 | 点击后使用标准显示截图，并继续核对当前应用、窗口和两帧结果；补点时钟按真实手势时刻计算 |
| 端侧首页误判挡住 AI | 未知首帧可以交给模型复核，后续继续遵守每会话采样上限 |
| 窗口截图比例不符只能停止 | 非全屏窗口截图与显示比例不符时，尝试标准显示截图，并继续执行比例及归属校验 |
| 停用同场景目标连带挡住其他目标 | 用户停用仅作用于同一关闭目标；自动等待重学仍显示在待处理任务中 |
| 切换模型或修改位置后旧异步结果可能回写 | 图片复核加入受管理任务；配置与学习修订校验，旧结果不能恢复旧成功状态；关闭气泡不取消学习 |
| 401/403/404/451 后持续重试 | 记录明确服务状态并暂停新请求，用户重新保存或测试后恢复；本地已验证路径保留 |
| 节点请求耗尽全局预算，图片不确定后没有机会复核 | 节点、图片各最多两次，总计最多四次；不确定或与本地广告控件证据矛盾时采用短间隔去重 |
| 明确“广告＋跳过”仍依赖远端定位 | 同一文字跳过与广告标志跨帧成立时，用当前 OCR 位置生成端侧候选；图片和 AI 继续处理歧义目标及复核结果，用户停用和重试退避仍生效 |
| Jev 图片判断缺少本地已经确认的公开证据 | 图片 state 增加广告标志、关闭框和倒计时的结构化提示；不包含原始 OCR 全文。广告概率与可点击阈值分别表达，90% 动作门槛保持 |

## 提示和人工纠错

每个检测会话只显示一次固定的“TiaoTiao 正在检查”，约 1.2 秒后移除，不跟随识别或结果阶段重新弹出。移除截图时隐藏/恢复气泡的行为，避免反复闪动。气泡不接收点击、不抢焦点，管理界面关闭后由无障碍服务继续检测；设置可关闭提示。

每条生成的智能方案保存遮挡后的识别图片及最近一次点击前图片，各自记录当时的坐标；同一方案更新后保留最新一份对应种类的图片。识别与动作位置分别标红圈，支持放大。在调整模式中点击图像或逐像素微调，保存为新目标并清除旧验证，执行时保留用户选点。历史实际点击截图不伪造为新位置。图片不进入规则 JSON 导出及同步，删除方案或清空结果时删除。

## Jev 官方接入

用户要求使用手机已保存的官方 Key，升级一次性选择 `TYPE_SAFE / jev-latest` 与 `JEV_OFFICIAL / jev-latest`。图片和控件同走官方 `https://api.typesafe.ai/v1/systemone`；保留实验图片标记、原生 assets、Box 与 Noul。官方 [模型文档](https://docs.typesafe.ai/models)及 [图片文档](https://docs.typesafe.ai/images)使用 `jev-latest`；不再把图片限定在 Vercel。DeepSeek 仍使用独立官方 Key，无自动跨提供方回退。

0.3.7 真机最初固定图片测试返回 451；用户开启代理后返回 401，重新填写官方 Key 后，官方图片测试成功 587 ms。这只证明该次连通性，不证明真实广告准确率或提前关闭。

## 0.3.9 图片编辑与直接确认

移除列表缩略图与详情中的模拟广告占位图；无原图如实显示，没有用模拟图替代。默认选择带实际照片的样本；旧样本可明确标注并参考同一目标任务最近的真实画面，保存时绑定该画面的上下文。点击前会补充实际识别截图，即使动作没有成功也保留纠正依据。

在详情页图片中直接双指或双击缩放、拖动和点选，保存及取消就在同一层；去掉四个箭头，加入操作提示。缩放和平移会被逆变换回原始图片归一化坐标，空白边缘不会成为目标。未放大时允许正常滚动页面，放大后拖动图片。全屏仅为可选查看，不再是编辑必经入口。

“确认方案正确”单独存储绑定当前行为和时间的人工确认，立即进入已验证状态；不增加或伪造 AI 成功次数。确认会更新学习修订，旧异步结果无法回写；修改位置、重新学习与导入均清除相应旧确认。人工确认不再触发强制自然观察，也不因缺少提前关闭时间重新降为学习中；明确失败仍可暂停方案。

用户要求清空旧数据后，已实际删除手机普通/智能规则、图片、待识别样本、诊断截图、基线及学习缓存，逐项核对为零；API 配置和 59 个已选应用保留。本轮电脑临时保存的真实手机诊断图片副本也已删除。此后只在隔离模拟器验证 UI，没有向手机重新注入测试方案。

最终核心 JVM 78 项与 Android JVM 24 项通过。详情页 UI 回归 `OK (6 tests)`，35.689 秒，实际执行了 3 倍放大后选点、保存、检查历史图片未覆盖、人工确认激活且 AI 成功数为 0，并验证旧样本无需展开即可编辑。人工确认、修改位置、外部导入及坐标逆变换另外有独立单元测试。新版本已安装，用户清空后自行生成的方案保留，未继续在手机自动创建测试数据。
