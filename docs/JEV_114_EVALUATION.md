# Jev 1.14 实际接入与实测

日期：2026-11-03，时区 Asia/Shanghai。版本 0.3.5，versionCode 20。未 commit 或 push。

本文件记录 0.3.5 的历史状态；0.3.6 已另行接入 DeepSeek 官方直连，见 [后续实测](DEEPSEEK_OFFICIAL_EVALUATION.md)。

## 实际接入

- 当前手机的控件模型和图片模型均为 `typesafe-ai/jev-1.14.0`，使用已保存的 Vercel 网关密钥。
- 图片通过 `https://ai-gateway.vercel.sh/typesafe/v1/systemone`，请求包含原生图片 assets 与 `TypeSafe-Danger-Zone-Images: true`；最长边 1536 像素，保留既有文字遮挡。
- 广告判断使用 Noul，目标定位使用 Box；结果检查分别判断两帧首页、广告消失、详情/登录/购买页、系统提示。不确定时不晋升；原跳过文字仍在时不接受成功。
- 已在该兼容入口实际取得图片 Box 与 Noul 响应。提供方将图片和 Box 标为实验性，此结果不代表其他 Gateway 接口支持同样协议。
- DeepSeek 没有接入。设置页与首页下方配置卡分别显示控件模型和图片模型。

## 大麦实景

| 场景 | 实际记录 | 结论 |
| --- | --- | --- |
| 首轮图片识别 | 1476 ms 返回目标；Box `[.89,.06,.96,.09]`，本地 OCR 校准中心后执行 | 确认调用 Jev 图片接口 |
| 首轮结果 | 两帧真实首页，原广告与跳过按钮消失；最低判定把握 .94 | 时序不足，保留候选 |
| 观察自然结束 | 本轮不点击；复核 1870 ms，输入 8834 tokens；记录下界 2577 ms | 下界不是广告的精确固定时长 |
| 缓存复用 | 未重复请求目标识别；复核 1675 ms / 8818 tokens，最低把握 .98 | 提前关闭依据不足 |
| 更早执行缓存目标 | 当前唯一 OCR 目标即可执行；复核 2398 ms / 8820 tokens，最低把握 .96 | 首个结果帧距触控前画面 3552 ms，超过保守剩余 2577 ms，未计成功 |

大麦规则仍为候选，符合提前关闭条件的成功会话数为 **0**。取得首页画面不能单独证明点击使广告提前结束，当前不能宣称稳定跳过或 Jev 比其他模型准确。

用户明确手动为短点之后等待关闭。此前增加触控时长的假设未被证实；后续应分别测量发出点击、广告退出、首页稳定和截图可用的时间，区分应用响应与观察延迟。

## 价格

[Vercel 模型页](https://vercel.com/ai-gateway/models/jev-1.14.0) 当前标价 **$0.04 / 百万输入 tokens**。图片按输入 tokens 计费，响应的 input_tokens 包含图片，见 [TypeSafe 图片文档](https://docs.typesafe.ai/images)。

本次一条三图结果检查使用 8818 tokens，按该输入单价约 **$0.00035272**。这只是一条请求的输入费用，不是整个测试或每张图片的固定费用。

## 验证及下一步

核心 JVM 59 项、Android JVM 18 项通过。API 36 模拟器完整回归 `OK (10 tests)`，98.549 秒，其中 9 项功能通过、按需性能采样跳过。原生图片回归检查版本、实验标记、尺寸、Box/Noul 解析、原跳过按钮对模型误报的否决、缓存、跨窗口及离线复用。模型响应为隔离模拟；真机结果以表中记录为准。

最终模型展示界面单独复查通过 `OK (1 test)`，11.551 秒；测试驱动先清除过期无障碍缓存，保留原断言。最终 APK 已安装并核对哈希一致，详见 artifacts/VERIFICATION.md。

建议保留同一执行与观察逻辑，以可切换模型做真实启动场景 A/B，分别比较广告识别、定位、首页误判、完整请求耗时和实际提前关闭率。每轮只使用一个模型，区分首次学习与缓存执行，不直接比较不同提供方的置信数字。是否加入 DeepSeek 由后续用户指令确定。

已知限制：部分非全屏窗口的截图比例与屏幕不一致时仍停止坐标使用；菜鸟本次没有广告，不能计为成功样本。当前样本量不足以估算总体准确率。
