## 大麦对照

同一台小米 14 Pro，Android 16，逻辑屏幕 1080×2400；不是把物理 1440×3200 直接当作触控坐标。系统显示截图右上角的关闭目标约在 (1000,165)，与已有窗口图片的目标接近。本轮没有证据证明大麦的这次故障由整体坐标缩放引起。

| 方式 | 从开屏窗口获得焦点至首页获得焦点 | 观察 |
| --- | ---: | --- |
| 暂停自动动作，不点击 | 3163 ms | 自然结束对照 |
| ADB 即时 tap | 3028 ms | 没有明显提前结束 |
| 无障碍 80 ms，辅助工具声明已启用 | 3132 ms | 完成回调及受控补点均未证明有效 |
| 无障碍 120 ms | 3121 ms | 单独增加时长无明显改善 |
| 无障碍 120 ms，控件内移动 1 px | 3138 ms | 增加微小移动也无明显改善 |
| 系统 touchscreen stationary swipe，120 ms | 1394 ms | 命令完成后约 275 ms 进入首页，明显早于上述自然结束 |

这是单次逐项对照，广告素材可能变化；它支持触控路径存在差异，不能证明大麦内部具体用了哪一段反模拟代码，也不代表已解决所有广告。后续必须以应用实际采用 Shizuku 的记录和多次提前退出为证据，不把 adb 手动注入成功直接称为应用端完整通过。

## 当前执行方式

所有应用共用流程，没有生产包名分支。增强点击默认关闭，用户明确开启并授予 Shizuku 权限后使用。Binder 采用官方 provider 和 UserService 接口；provider 由签名权限保护。用户服务仅接受预期包名、整数触点、显示尺寸和短暂有效期，不提供任意命令执行接口。

用户服务在 shell 身份下再次读取系统前台及逻辑显示尺寸，拒绝离开目标应用、屏幕旋转、越界、过期及过密请求，再执行固定 120 ms 系统触摸。方法返回失败或发生远端错误后，不补发无障碍点击；只有根本没有取得增强服务时才允许使用普通通道。

普通坐标通道使用 100 ms 短点，显式选择主显示屏；同一触控互斥执行，协程取消后继续等待已提交手势完成/取消或有界超时。节点规则仍先校验原生目标，不将过期节点坐标变成盲点。

## 位置与结果修复

之前将窗口截图按整屏比例使用，即使比例接近也可能漏掉窗口原点和系统栏。现统一使用显示截图，以及系统报告的完整逻辑屏幕尺寸，窗口边界之外的目标禁止触控。OCR 校准必须与原目标区域相交，不能跳到附近但不相交的控件。

点击前在保存识别图片之后重新截图，比对关闭区域和画面结构，变化则取消旧位置、继续检测。受控补点也重新检查。手动选点不会在补点时被 OCR 中心覆盖。日志记录实际通道、整数像素、逻辑屏幕尺寸和按压时长；显式诊断记录每次触控请求，而不是只画模型给出的框。

修复人工确认方案的结果措辞：观察到首页但缺少提前关闭时序时，保留人工确认，同时明确不把自然结束计为本次点击成功。

## 0.3.12 内置配对、启动与运行状态

versionCode 27，2026-11-03。当前版本移除 Shizuku API/provider，使用本机无线 ADB 身份启动只服务于 TiaoTiao 的 shell 进程。交接 provider 由系统签名权限及 shell/root UID 双重限制，Binder 固定绑定本应用 UID，仅保留前台校验后的坐标点击接口。本机 RSA 身份单独加密，不与 AI 密钥混用。

系统无线调试页面暂停会关闭配对弹窗，返回 App 输入配对码不可作为主要流程。主动开启两分钟辅助后，仅精确查询系统设置的 `pairing_code` 与 `ip_addr` 控件；刷新控件后连续两次同窗同值、当前 mDNS 端口一致时才提交。读取不到则在同一系统页面使用不抢焦点的浮层数字键盘；浮层自动避开可读取的配对码/地址区域，支持拖动标题。没有通知输入、系统输入法或分屏要求。

启动使用本机连接的交互 shell 会话，保持会话直至独立进程完成 Binder 回连，再关闭连接。此前单次命令会话结束后没有收到服务回连，曾出现配对成功、启动失败；修订后手机复用保存身份约 2 秒进入实际 READY，关闭本机启动连接后服务持续可用。没有用电脑直接启动 shell 服务替代这次验证。

设置卡片以实际服务连接显示运行、未启动或启动失败，并同步替换启动/停止按钮；停止时立即清除本地连接状态。辅助界面重建只释放本实例监听器，不取消仍有效的配对会话；真正服务断开、用户结束或超时则结束辅助并清理输入。

核心 JVM 80 项、应用 JVM 40 项，构建和 Lint 通过。API 36 隔离模拟器定向 `OK (3 tests)`，9.269 秒，覆盖浮层数字输入仍保留 Settings 焦点且不打开输入法、取消清理、无外部管理器的独立服务、真实触点、跨前台拒绝、运行/停止界面状态同步及独立加密身份。该记录不代表本轮重新验证了第三方广告识别或所有自动学习分支。
